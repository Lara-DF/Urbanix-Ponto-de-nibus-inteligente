Instituição: ETEC da Zona Leste
Curso: Desenvolvimento de Sistemas/ AMS

Categoria: Tecnologia, Mobilidade Urbana e Acessibilidade

Equipe: Julia Costa, Lara de Freitas, Mariana Pereira e Nicolly Lucia. 


Tecnologias utilizadas no desenvolvimento web

- HTML5: Estruturação dos elementos e seções da página.
- CSS3: Estilização, layout responsivo e identidade visual.
- JavaScript (Vanilla): Interatividade, controle de funcionalidades e integração com recursos do navegador.
- Three.js: Renderização e animação de modelos 3D interativos.
- Web Speech API (SpeechSynthesis): Reprodução de informações por voz.
- PHP: Processamento de informações no servidor.
- PDO: Comunicação com o banco de dados e execução de operações.


Tecnologias utilizadas no protótipo físico

- C/C++: Programação do ESP32.
- Arduino IDE: Ambiente de desenvolvimento.
- ESP32: Unidade de controle do sistema.
- API Olho Vivo (SPTrans): Consulta de informações dos ônibus.
- Wi-Fi: Conexão com a internet.
- NTP: Sincronização de horário.


Componentes eletrônicos

- Display Nokia 5110.
- DFPlayer Mini.
- Cartão microSD.
- Alto-falante 3W 4Ω.
- Sensor DHT22.
- LEDs indicadores.
- Botões de interação.
